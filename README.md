## ✨ Features

- 🛍️ Product listing & details
- 🔐 User authentication
- 🛒 Shopping cart system
- ❤️ Wishlist functionality
- 🔍 Search products
- 📱 Responsive UI across devices

---

## 🏗️ Architecture & State Management

- 🧱 Clean Architecture (Separation of concerns)
  - Presentation Layer
  - Domain Layer
  - Data Layer

- ⚙️ State Management:
  - BLoC Pattern (Cubit)

This ensures:
- Scalability
- Maintainability
- Testability
